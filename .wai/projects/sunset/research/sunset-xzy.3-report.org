** Pinned semantics recorded (module docstring + code)

- Ink iff gray value strictly below recorded threshold (fixed-threshold);
  disabled/unapplicable binarization → unknown =binarization-not-configured=.
- Source simplification parsed as =ink-dilation-<N>px= → 8-connected
  (square/Chebyshev) dilation of the ink mask, =ink-dilation-0px= valid
  no-op; =none= or unparseable → unknown =source-simplification-missing=.
- Regions: descriptor points, (x,y) minimal corner; ink-claim agrees iff
  min ≤ measured ≤ max; no-ink agrees iff measured ≤ min; page agrees iff
  all regions agree AND whole-page fraction within [min, max]; out-of-bounds
  or malformed claims → region =differ=, id retained.
- Pinned unknown-check order: unavailable → binarization → decode
  (=render-decode-failed=, new documented reason) → simplification → frame
  (carries frames.py reason) → calibration (=uncalibrated=).
- Aggregate: pass only if every outcome agree; empty set → blocked
  (=no-page-outcomes=); blocked reasons list carrier/page/status/reason.

** Deviations (all within brief discretion)

1. RED failure class ImportError vs ModuleNotFoundError — same gate, noted above.
2. Rotated-carrier fixture: built as a plain landscape 792×612 synthetic PDF
   with ink drawn at the hand-computed rot90-frame-predicted pixels
   (descriptor box (50,350)-(450,750) → raster (350,50)-(750,450)) instead of
   pymupdf =set_rotation=. Reason: probing showed =set_rotation(90)= +
   pymupdf drawing + poppler produced ink placements that did not match
   naive derivation (blob center offset −28px vs prediction), and pymupdf
   drawing coordinates change meaning when rotation is set before drawing.
   The oracle-under-test only sees (raster bytes, declared frame), so the
   provenance of the raster is irrelevant; the wrong-frame (rot180) run
   flipping the verdict proves the frame is what drives the comparison.
3. =_evaluate= helper needed a non-None sentinel for "no calibration" (an
   explicit =calibration=None= must reach the oracle); also carrier helper
   gained =white_rects= / =blank_pages_after= (white hole punched after black
   fill; genuinely blank page 2 of the same document). Test-only fixes.
4. SCOPED_CLAIM-in-docstring asserted with whitespace-normalized containment
   (catches wording drift, tolerates line wrapping).
