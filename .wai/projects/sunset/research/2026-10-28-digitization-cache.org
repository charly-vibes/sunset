** Request and selection contracts
Each recognition key hashes canonical versioned JSON binding ordered source and
render digests; region identity/role; crop/page/frame/DPI/rotation/scale;
implementation code/consumer/Unicode/renderer versions; complete recorded
provider/model identity and explicit unavailable revision; and effective prompt,
schema, language, preprocessing, decoding and policy. Per-region overrides merge
by local ID, replacing individual fields; changed prompt/crop affects only its
region under otherwise identical inputs. Page rendering and detection import
still execute in this slice; only region recognition is cached.

Public run adds --cache CACHE_DIR, repeated --fresh REGION_ID and repeated
--select REGION_ID=ATTEMPT_ID. Recorded response changes alone cannot replace a
cached selected result. A fresh run selects its new output for that run, keeps
all previous outputs, and never updates the cache's first-default pointer.
Explicit selection is pinned to a valid retained attempt under the same request.
Unknown/conflicting flags or unavailable selection refuse publication.

Requests and response blobs are verified before reuse; fresh output admission
also verifies any existing request metadata first. Response schemas are checked
on admission and reading. Attempt envelopes have nonce plus request/output
bindings and content-addressed identities; exclusive atomic publication retains
concurrent attempts without overwriting an earlier selection. Corrupt entries
return cache-integrity-failure with no provider call or published run; no silent
repair/substitution. Each run copies known response bytes and attempt envelopes
locally; operations.json and manifest pin the same selections. Existing source-
linked inspection exposes keys, requests, selections, alternatives and cache usage.
Unavailable model revisions stay null/false; fresh determinism is not claimed.
