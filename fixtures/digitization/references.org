* Reader protocol (independent reference judgments)

References are new judgments; existing region sheets (905.3, r68 carrier
annotations) are NOT transcription gold and are not repurposed. Two
independent readers, different model families where available, each produce:

1. Full region inventory with coverage dispositions (text / handwriting /
   image / caption / decoration / page furniture); nothing silently dropped.
2. Verbatim text per text region (Spanish, accents preserved; uncertain
   characters marked, never smoothed).
3. Poem geometry on the difficult page: line breaks, stanza boundaries,
   indentation per stanza.
4. Scoped reading order (per column; column order declared).
5. Image/caption relationships (directed, scoped).
6. Timing noted; unknown is an answer.

Disputed items stay explicit: the agreement matrix records AGREE / COMPATIBLE
/ DISAGREE / UNKNOWN per item; DISAGREE and UNKNOWN items become manifest
=exclusions= with counts and reasons. No winner election, no smoothing.
Reviewer identity, scope, per-reader sheet digest and agreement matrix are
recorded here before any candidate run. Agent-executed readers are a recorded
deviation: a human pass supersedes, and the owner explicitly rules whether
this reference supports assessment mode or only engineering-only execution.
