* Purpose

Real PDF/EPUB carriers prepared for sunset-r68.11 ("Real PDF/EPUB fixtures and
adapters preserving source observations", tasks.md 3.1). All PDFs now carry
reader annotations (Highlight/Text/Underline/StrikeOut/FreeText/Square) so
=pdf:annotations= adapters have real human-style observations to preserve.
The EPUB carries a CFI-annotation sidecar.

* PII screening and redaction (2026-10-14)

Screened with pdftotext/pymupdf/pikepdf over full text, docinfo, XMP,
annotation contents, and embedded-file scan. No personal data in any fixture:

- no CUIT/CUIL/DNI, CBU, account, or reference numbers (redacted where present)
- no real person or business names (redacted to MOCK values)
- no real addresses or bank names (redacted to mock addresses / "Banco Mock")
- no embedded attachments; no XMP identity data (only public ISBN)
- excerpt docinfo scrubbed to Title + sampler producer string

Redaction method: pymupdf =add_redact_annot= (real content removal, not
overlay), mock text written back at the same coordinates; post-redaction text
re-screened clean.

* Layers deployed

Two scripted reader personas ran in isolated sandboxes over identical
pristine carriers (details and agreement analysis in reader-agreement.org):

- Top-level *.pdf: carriers + reader-A layer ("Dr. Elena Sacriste", careful
  academic: 1 Highlight/Square anchor + 1 ES: Text note per file).
- reader-b/*.annotated.pdf: identical carriers + reader-B layer ("Ing. Rafa
  Quiroga", skeptical QA: 1 StrikeOut/Ink anchor + 1 RQ: FreeText/Text note
  per file), plus annotate.py as generation provenance.
- reader-a-epub-annotations.json / reader-b-epub-annotations.json: two
  disjoint CFI annotation sets for sunset-carrier-sample.epub.
- Placeholder reader-mock annotations were removed from all deployed layers.

Region agreement between readers: 1/10 files (bank-statement saldo row,
100% overlap); same first page chosen 10/10. See reader-agreement.org.
